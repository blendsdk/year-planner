# Third-party notices

The React package contains colour values derived from two public palette
catalogues. No runtime code from these projects is bundled.

## Material 2014 palette

The `material-*` presets use colour values from the Material Design 2014 named
palette, as published by MUI:

- Source: <https://mui.com/material-ui/customization/color/>
- Package: `@mui/material` 9.5.0 (`colors` export)
- Licence: MIT

## Fluent UI v9 palette

The `fluent-*` presets use colour values from the public Fluent UI v9
`webLightTheme` token set:

- Source: <https://react.fluentui.dev/>
- Package: `@fluentui/react-components` 9.75.1
- Licence: MIT

The upstream packages retain their own copyright and licence texts. Their full
licence files are available with the upstream distributions and repositories.
These notices cover the palette values only; the planner does not depend on
either design system at runtime.
