# @blendsdk/year-planner-languages

### Minor Changes

- Add 45 locale catalogues covering 41 left-to-right languages, including
  Eastern Armenian, the European set and the Asian left-to-right set. The
  package exports one subpath per locale, a locale resolver with English
  fallback, and complete planner-owned UI and screen-reader messages.
