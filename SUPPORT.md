# Support

Year Planner for React is a source-available project with **best-effort
community support**. There is no SLA, no guaranteed response time and no 24/7
support.

## Where to ask

- **Bug reports and feature requests:** open a GitHub issue in the GitHub issues list.
- **Usage questions:** open a GitHub issue with the `question` label.
- **Security reports:** use GitHub private vulnerability reporting as described
  in [SECURITY.md](./SECURITY.md). Never open a public issue for a suspected
  vulnerability.

## Supported versions

The current `0.x` line is supported. Older pre-1.0 minor versions are supported
on a best-effort basis; fixes normally land on the latest minor.

## Release cadence

Releases happen as needed. There is no fixed calendar promise. Security fixes
are prioritized.

## Commercial support

There is no commercial support tier or paid SLA. The project is
community-supported under the [internal-use licence](LICENSE). Separate
permissions are not included in free support. Contribution terms are in
[CONTRIBUTING.md](CONTRIBUTING.md).
